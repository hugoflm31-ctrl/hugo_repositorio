# UPlay 

## Descripción del proyecto

UPlay es una propuesta de red social enfocada en estudiantes que disfrutan de los videojuegos. Su objetivo es conectar jugadores, facilitar la creación de amistades y permitir que compartan sus intereses y experiencias dentro del mundo de los videojuegos.

## Avance del proyecto

Actualmente se ha desarrollado la primera estructura de la base de datos utilizando MySQL.

### Tablas implementadas

1. USUARIO
2. CUENTAVIDEOJUEGO
3. VIDEOJUEGO
4. USUARIO_VIDEOJUEGO
5. CLIP
6. EVENTOS
7. EVENTO_USUARIO
8. GRUPO
9. MIEMBRO_GRUPO
10. AMISTAD
11. REACCION
12. NOTIFICACION

### Tecnologías utilizadas

- MySQL
- MySQL Workbench
- SQL
